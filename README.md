# ApplyFlow

ApplyFlow is an application intake and screening platform for organisations.

## Foundation

The first phase establishes:

- React + TypeScript + Vite
- A responsive admin shell
- Organisation/workspace navigation
- Application dashboard and application list
- Supabase/Postgres schema foundation
- Organisation-level data isolation with Row Level Security

## Run locally

```bash
npm install
npm run dev
```

## Architecture roadmap

1. Foundation and authentication
2. Application management
3. Form builder and versioning
4. Applicant experience
5. Eligibility rules
6. Scoring
7. AI-assisted screening
8. Review teams
9. Shortlist and final selection
10. Analytics and reporting
11. Notifications
12. Production hardening

AI-assisted screening is advisory. Final selection remains a human-controlled workflow with audit history.
